小龙虾本地版首次使用

1. 解压压缩包。
2. 双击“启动小龙虾.bat”。
3. 浏览器会自动打开小龙虾后台。
   如果当前目录已经在运行，只会重新打开网页；如果旧安装包占用了端口，才会切换到当前目录的新服务。
4. 如果要彻底关闭后台服务，双击“停止小龙虾.bat”。
5. 先进入右上角“设置”，配置模型 API。
6. Notion、素材图生成、Hermes Worker、交付门禁默认关闭，需要时再到“模块与插件”里开启。
7. 入口助手默认未连接，需要微信入口时进入“入口助手”页面扫码连接。
8. 交付包不包含任何预置 API Key、Notion Token、微信登录状态或历史数据。
