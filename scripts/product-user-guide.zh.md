# 小龙虾本地版使用说明

## 这个包里有什么

- 小龙虾后台页面
- 本地 API 服务
- 任务中心、发布包、情报库、知识库、模块与插件、系统日志
- 内置 Node.js 运行环境
- 首次运行后自动创建本地数据目录和日志目录

## 这个包里没有什么

- 不包含模型 API Key
- 不包含图片 API Key
- 不包含 Notion Token 或 Database ID
- 不包含微信登录状态
- 不包含你的历史任务、发布包、图片和日志
- 不要求用户安装 OpenClaw
- 不要求用户安装 WSL
- 不要求用户安装 Node.js

## 首次使用

1. 解压压缩包到一个普通本地目录，例如 `D:\Xiaolongxia`。
2. 双击 `启动小龙虾.bat`。
3. 浏览器会自动打开 `http://127.0.0.1:3200/`。
4. 进入右上角“设置”，配置模型 API。
5. 保存设置后，进入“任务中心”创建任务。

## 关闭网页后怎么重新打开

关闭浏览器页面不会删除任务、配置或发布包。

需要重新打开后台时，再次双击 `启动小龙虾.bat` 即可。脚本会先判断当前目录的小龙虾是否已经运行：如果已经运行，只打开网页；如果端口被其他旧安装包占用，才会停止旧服务并启动当前目录的新服务。

如果有任务正在运行，建议等任务结束后再重新双击启动。

## 如何停止本地服务

如果要彻底关闭小龙虾后台服务，双击 `停止小龙虾.bat`。

它只会停止当前解压目录启动的小龙虾本地 API 和微信 Bridge，不会删除配置、任务、发布包或日志。

如果你解压过多个版本，直接双击新目录里的 `启动小龙虾.bat` 即可；它会自动处理旧服务占用 `3200` 端口的问题。

## 必填配置

核心功能只需要配置模型 API：

- `Provider ID`：模型提供方标识，例如 `openai`、`deepseek` 或你的代理服务名称
- `模型`：模型名称，必须与 API 服务支持的模型名一致
- `Base URL`：OpenAI 兼容接口地址
- `API Key`：用户自己的模型密钥

配置完成后，就可以使用任务中心、小红书发布包生成、本地发布包保存、步骤日志和 token 消耗统计。

## 入口助手

入口助手默认未连接。

- 交付包不会携带任何已有微信登录状态。
- 需要微信入口时，进入“入口助手”页面。
- 点击连接或重新连接后，用微信扫描二维码。
- 不需要微信入口时，可以保持断开状态。

## 可选模块

这些能力默认关闭，不影响核心使用：

- Notion 接入：填写 Token 和 Database ID 后再开启。
- 素材图生成：填写图片 API 的 Base URL、模型和 API Key 后再开启。
- Hermes Worker：高级研究增强能力，默认关闭，不是核心依赖。
- 交付门禁：额外终审步骤，默认关闭，需要更严格复核时再开启。

## 小红书自动预填

安装包已内置便携 Python 和 Playwright，自动预填不再要求用户单独安装 Python 或 Playwright。

自动预填仍需要本机存在 Chrome 或 Edge 浏览器，并且需要用户在浏览器中登录小红书创作中心。如果没有检测到可用浏览器，预填会失败并在页面或日志中提示。

## 本地数据位置

首次运行后，解压目录下会出现：

- `data\runtime`：本地数据库和运行数据
- `data\openclaw`：用户本机配置
- `logs`：本地 API 启动日志

## 常见问题

### 双击后页面没有打开

手动访问：

`http://127.0.0.1:3200/`

### 启动失败

查看：

`logs\api.err.log`

### 模型调用失败

检查：

- Base URL 是否正确
- API Key 是否正确
- 模型名称是否被服务商支持
- 当前 API 是否兼容 OpenAI 格式

### Notion 或图片生成失败

先保持对应模块关闭，确认 Token、Base URL、模型名、Database ID 验证通过后再开启。

## 产品定位

小龙虾本地版是一个本地优先的内容工作台。解压运行，配置自己的模型 API 后，就可以在本机使用任务生成、发布包管理、日志追踪和成本统计能力。
